# Conteúdo de adestramento

Os exercícios, programas e desafios do Patinha ficam aqui, como dados versionados (ADR-04).

- `exercicios/<slug>.json`
- `programas/<slug>.json`
- `desafios/<AAAA-MM>.json`

**Regras:**
- Use a skill `licao-adestramento` para escrever e revisar.
- Valide com `python .claude/skills/licao-adestramento/scripts/validar_conteudo.py content/`.
- Nada é publicado (`"published": true`) sem a revisão do adestrador parceiro (`reviewed_by` + `reviewed_at`) e sem vídeo.

Os arquivos atuais são **exemplos** (rascunhos, não publicados) para o desenvolvimento. O adestrador parceiro revisa e substitui.
